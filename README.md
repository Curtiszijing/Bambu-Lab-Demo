## 📂 Project Overview

### 1. MakerWorld Launchpad (Interactive UI Demo)
A community-driven crowdfunding and incubation platform prototype.
* **Core Concept:** "From First Print to Fame."
* **Key Features:** Integrated 48-hour crowdfunding windows, points-based voting/locking mechanisms, and a "Founding Wall" for backer recognition.
* **Objective:** To lower the barrier for creators to monetize their designs while increasing user stickiness through "Believer" rewards.

### 2. MakerWorld Creator Challenge (Show Bible)
A strategic proposal for a YouTube-native "light reality show" competition.
* **The Format:** A 10-episode series featuring a "Blind Audition" format to ensure a meritocratic, product-first focus.
* **Strategic Goal:** Designed to break the "tech bubble" and attract non-3D printing audiences through viral segments like the "3-Year-Old Laughter Challenge."
* **Business Value:** A lean production model (Budget: ~¥1M) targeting 20M+ equivalent media value (EMV) impressions.
